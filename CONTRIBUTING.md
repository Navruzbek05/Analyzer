# Contributing

Thanks for your interest! Issues and pull requests are welcome in English or Russian.

1. Fork the repository and create a branch: `git checkout -b my-fix`
2. Install dependencies: `pip install -r requirements.txt`
3. Make your change in `arch_analyzer.py`
4. Run the check: `python test_arch_analyzer.py` (should print `OK`)
5. Open a pull request with a short description of what and why

Keep it simple: the project is a single script with one dependency (`rich`).
